### 🛠 Tech Stack
* **Framework:** Flutter
* **State Management:** Bloc
* **UI Components:** * `flutter_svg` for icons
    * `pinput` for OTP/PIN entry
    * Custom Poppins Font

---

### 🚀 Getting Started
1. Clone the repository.
2. Run `flutter pub get` to install dependencies.
3. Run the app using `flutter run`.
